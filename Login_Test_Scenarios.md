# Login Page - Test Scenarios

## Objective
To verify that the login functionality works correctly under different conditions.

## Test Scenarios

| Scenario ID | Test Scenario | Priority |
|---|---|---|
| TS_LOGIN_001 | Verify login with valid credentials | High |
| TS_LOGIN_002 | Verify login with invalid credentials | High |
| TS_LOGIN_003 | Verify validation when username is empty | High |
| TS_LOGIN_004 | Verify validation when password is empty | High |
| TS_LOGIN_005 | Verify password masking | Medium |
| TS_LOGIN_006 | Verify login using the Enter key | Medium |
| TS_LOGIN_007 | Verify behavior after multiple failed login attempts | High |
| TS_LOGIN_008 | Verify logout after successful login | High |
| TS_LOGIN_009 | Verify leading and trailing spaces in input fields | Medium |
| TS_LOGIN_010 | Verify login page behavior on different screen sizes | Medium |

## Notes
These scenarios are examples for practice. Validate expected behavior against the application's requirements before executing them.
